# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Astrivya, please report it privately:

- **Email**: security@astrivya.ai
- **GitHub**: Use the [private vulnerability reporting](https://github.com/astrivya/astrivya/security/advisories/new) feature

Please do **not** open public issues for security vulnerabilities.

## Response Timeline

We will acknowledge receipt of your report within 48 hours and provide an estimated timeline for a fix.

## Scope

This policy applies to the latest release of all packages under `@astrivya/*`. For vulnerabilities in dependencies, please report to the respective project.
